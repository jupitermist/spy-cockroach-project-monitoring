# Purpose-Driven Agentic Project Monitoring

## SPY COCKROACH

A proof of concept inspired by the behavior of spy cockroaches.

> The core principle is simple:
> what an agent can access should not determine what it retrieves.

> The system therefore treats "do not retrieve"
> as an explicit design decision—not as an accidental absence of data.
